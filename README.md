# Metoriya — Hospital Management System

Metoriya is a modern hospital operations dashboard designed to demonstrate production-style healthcare software architecture.

## Current MVP

- Hospital overview dashboard
- Patient directory with search
- Appointment schedule
- Medical records, pharmacy, staff and reports module shell
- Patient registration dialog
- Responsive desktop and mobile layout
- TypeScript + Next.js App Router
- Tailwind CSS v4

## Roadmap

Authentication, role-based access control, PostgreSQL persistence, doctor workflows, electronic medical records, pharmacy inventory, billing, audit logs and reporting will be added in later iterations.

> Demo application: not intended for real clinical use or storage of real patient information.
